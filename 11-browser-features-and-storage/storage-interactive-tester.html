🗄️ Browser Storage Comparator

Inspect and experiment with LocalStorage, SessionStorage, and Cookies side-by-side.

LocalStorage Persistent (5-10MB)

Survives tab close and browser restarts. Shared across all tabs with the same origin.

SessionStorage Tab Lifespan (5MB)

Only exists for this specific browser tab. Opening a new tab creates fresh storage!

Cookies Sent with HTTP (~4KB)

Sent to web servers on each request. Can have custom expiration times.
